# liquidity-platform
# Платформа ликвидности (MVP) — Хакатон 

Цифровая платформа для организации трансграничного финансирования между юридическими лицами. Соединяет российских заемщиков с зарубежными кредиторами, предоставляя прозрачный механизм сравнения офферов и расчета полной стоимости.

**Ссылка на развернутый проект:** https://sber-delta.vercel.app

## 🚀 Реализованный функционал
Сквозной сценарий от регистрации до согласованной сделки:
*   **Роли:** Заёмщик (РФ), Кредитор (зарубежье), Оператор, Администратор. Самостоятельно можно зарегистрироваться только заёмщиком или кредитором; сотрудников создаёт администратор.
*   **Регистрация юрлиц:** название компании, ИНН (заёмщик, 10 цифр) или страна и регистрационный номер (кредитор).
*   **KYC/AML:** загрузка пакета документов (PDF), проверка администратором: одобрение или отказ с причиной, которую видит компания; после отказа документы загружаются заново.
*   **Заявка:** сумма и валюта, страна получения, назначение, срок кредитования, способ передачи (SWIFT, СПФС, CIPS, платёжный агент). Перед публикацией заявка проходит модерацию администратором (публикация или отказ с причиной).
*   **Кредитор:** фильтры заявок по стране, валюте, сумме и сроку; предложение — сумма к выдаче, ставка, комиссия за организацию, дополнительные условия; список своих предложений со статусами.
*   **Оператор:** проверка предложений (сумма не больше запрошенной, ставка больше 0) и решение показать/скрыть с причиной; подтверждение сделки только при загруженном договоре и одобренном KYC обеих сторон.
*   **Сделка:** заёмщик принимает или отклоняет предложения; чат и документы сделки; статусы «В работе» → «Согласовано».
*   **История и архив:** у каждой заявки журнал событий (кто и когда что сделал); у заёмщика и администратора — все заявки во всех статусах; архив согласованных сделок.
*   **Аналитика администратора:** количество заявок и предложений, доля заявок со сделкой, средний размер финансирования отдельно по каждой валюте, топ стран по спросу (куда нужны средства) и по предложению (откуда кредиторы).
*   **Безопасность:** ролевая модель на сервере, доступ к сделке и файлам только у участников и сотрудников, безопасные имена файлов, экранирование шаблонов (Jinja2 autoescape).

## 🛠️ Технологический стек
*   **Backend:** Python 3.12, FastAPI, Uvicorn
*   **База данных:** PostgreSQL 16, SQLAlchemy (ORM)
*   **Аутентификация:** JWT (python-jose), bcrypt (passlib)
*   **Frontend:** Jinja2 (Server-Side Rendering), Bootstrap 5, HTML/CSS
*   **Инфраструктура:** Vercel (serverless), Neon PostgreSQL

## ☁️ Деплой на Vercel
Vercel сам распознаёт FastAPI и запускает `main.py` (объект `app`), отдельная настройка не нужна.
Каждый push в `main` выкатывается автоматически, для других веток Vercel даёт превью-ссылку.

1. Vercel → **Add New → Project** → импортировать этот репозиторий с GitHub (Framework Preset: Other).
2. В проекте: **Storage → Create Database → Neon (Postgres)** и подключить к проекту — Vercel сам добавит `DATABASE_URL`.
3. **Settings → Environment Variables:** `SECRET_KEY` (длинная случайная строка), `ADMIN_EMAIL`, `ADMIN_PASSWORD` — первый админ создаётся при старте, если его ещё нет.
4. **Deployments → Redeploy**, чтобы переменные подхватились.

Таблицы создаются автоматически. Загруженные файлы хранятся в БД (таблица `stored_files`), потому что у Vercel нет постоянного диска.
Ограничение Vercel: размер одного запроса (файла) — до 4,5 МБ.
