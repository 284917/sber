## 🚀 Реализованный функционал
В рамках MVP на 20.10.2026 реализован сквозной сценарий сделки:
*   **Роли:** Заемщик (РФ), Кредитор (Зарубежье), Администратор
*   **Аутентификация:** Регистрация с выбором роли, вход по JWT, выход из системы
*   **Заемщик:** Создание заявки на ликвидность (сумма, валюта, страна, назначение) Просмотр предложений от кредиторов и принятие офферов
*   **Кредитор:** Просмотр опубликованных заявок. Отправка оффера (сумма, ставка, комиссия кредитора). Автоматический расчет итоговой комиссии (включая комиссию платформы 0.8%).
*   **Администратор:** Панель аналитики (всего заявок, средняя сумма, топ-стран). Модерация статусов заявок (публикация/отклонение)
*   **UI/UX:** Интерфейс выполнен в фирменном стиле Сбера (цвета, шрифты, компоненты)

## 🛠️ Технологический стек
*   **Backend:** Python 3.12, FastAPI, Uvicorn
*   **База данных:** PostgreSQL 16, SQLAlchemy (ORM)
*   **Аутентификация:** JWT (python-jose), bcrypt (passlib)
*   **Frontend:** Jinja2 (Server-Side Rendering), Bootstrap 5, HTML/CSS
*   **Инфраструктура:** Nginx (Reverse Proxy), Ubuntu 24.04
